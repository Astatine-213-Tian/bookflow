# EPUB 精校：审核、预览、确认、应用

通过 `book-management` 执行的逐本精校流程。适用于下载 EPUB 的版式、文字规范化、
封面和文件名／元数据整理。Codex 负责阅读上下文、判断结构和评估视觉效果；现有工具
负责清点、提出差异和验证。它不是统一重排所有书籍的一键命令，也不等于逐字校勘原著。

## 1. 建立本书基线

读取原文件并记录绝对路径、SHA-256、EPUB 版本、OPF、manifest、spine、NAV／NCX、
可见目录、封面声明与实际尺寸。清点各级标题、CSS、内联样式、链接、脚注、图片和字体。
先确定本次范围；提供的本地 EPUB 已确定输出类型，无需再问输出格式。
本地精校默认直接更新用户提供的文件，成品留在**原文件所在目录**；文件名需要清理时，
在同一目录改为 `书名.epub`。不把下载目录中的书转存到本仓库，除非用户另行指定。

原文件保持原样。按[存储约定](storage.md)把一次性探针、截图和候选预览放在系统临时
目录；未完成的审核清单与决定放在 `generated/updates/<task>/`。恢复时重新比对原文件
哈希，不能把旧预览的决定直接应用于变化后的书。

使用[现有 EPUB 维护](local-editions.md#existing-epub-maintenance)的只读检查：

```bash
uv run book-normalize "INPUT.epub" --check --no-metadata --no-codex-review \
  --report /private/tmp/bookflow-proofreading-normalization.json
uv run python src/cli/validate_epub_chapters.py "INPUT.epub"
```

`--check` 必须保留。第一条只提出共享规则的变化，不能把修复计数解释成已修复或已批准。
脚本输出的可疑项由当前 Codex 阅读上下文审查。出版书的资料以版权页和对应版次为证；
按需查出版社等来源，不默认套用晋江优先的元数据补全。

完成条件：记录章节覆盖、主要版式类型、文字风险、元数据证据和基线缺陷，能定位到
具体 archive member 与元素／段落。遇到固定版式、纯扫描、复杂竖排，单独说明可处理范围。

## 2. 分类审核与候选方案

文字规则以 [normalization.md](normalization.md) 为唯一通用来源。以下是精校的版式
决策和审核重点，不另写一套全局替换器。需要扩展通用文字规则时，另行同步实现、
可执行示例和测试；本书的例外写进审核决定，不悄悄改变其他书的行为。

### 标题、层次与留白

同一语义层级统一字重、字号、间距和对齐；不同层级保持区分。检查所有章首，不能仅
凭 `h1/h2` 或一个 class 推定层级。默认标题加粗、颜色继承阅读主题，避免固定黑色在
夜间模式失效。用 `em` 表达间距，消除靠空段落、连续 `<br>`、固定高度撑出的章首空洞。
区分排版空白与正文场景分隔，保护有锚点的空节点。

| 语义角色 | 首选候选 | 审核重点 |
| --- | --- | --- |
| 单纯章名、卷名 | 加粗、居中，紧凑章首 | 与正文之间有明确层次，不占半页 |
| 回目（回数＋两句标题） | 居中；回数略小，题句各一行 | 保留题句，不靠空格模拟换行；窄屏可自然折行 |
| 主标题＋副标题＋作者／出版社 | 紧凑的左对齐标题组 | 主标题突出，署名较小；居中可作备选 |
| 章内纯数字小节 | 小幅加粗、紧凑间距，左对齐作首选 | 保留原数字和顺序；必要时预览居中方案 |
| 含左对齐数字小节的篇章／部标题 | 标题也左对齐、加粗 | 上下共用同一条左边线，如《永远的尹雪艳》；优先于单纯章名居中的默认值 |
| 引文内部小标题 | 在引文块内加粗、通常居中 | 与叙述分开，不能当成新的目录章 |

精校采用上述数字小节候选时，这是对共享准备流程“中文数字＋居中 H3”默认值的明确
本书覆写。审核记录需列出受影响小节；不能随后再运行会覆盖此选择的普通准备流程。

章标题中的“返回目录”链接经检查目标后可去掉点击行为，保留文字、嵌套格式和全部
被引用的 `id`／锚点。目录跳往章节的链接仍有效。只移除确认的章标题回目录链接，
正文链接、脚注及其回链保留；标题中的注释链接另行处理。检查后代 `span/a` 的颜色，
不能只改外层标题。普通目录链接不在这个去链范围。

### 目录层级

将 NAV、NCX、可见目录与 spine 顺序交叉核对，优先保留原书有意义的卷、部、篇、章节。
若最外层节点只是重复整本作品书名（例如《纽约客》的顶级“纽约客”），且没有独立的
内容分组意义，去掉这个冗余包装层，将其子节点提升一级，原先的相对次序与内部层级不变。
无子项、只指向扉页的重复书名条目也可从目录移除；不要因此删除扉页上的书名或 metadata。
合集里的单篇作品名、同名但有独立内容的章节、分卷标题不能按书名匹配自动删除。
预览展示调整前后目录树；应用时同步 NAV／NCX／可见目录，维护锚点、NCX playOrder 与深度，
验证所有目标以及章节顺序，不能只把条目文字隐藏。

### 诗歌、献词和引文

先判断文体与边界，再选择样式。输入 class、居中、缩进或引号只提供候选证据；阅读
前后文，必要时对照用户提供的原版截图。已粘连的标题／引文只在边界可证实时拆分，
保留逐字内容和顺序。使用[引用审查](local-editions.md#review-possible-quotations)已有能力。

- **独立短诗**：标题与作者形成紧凑标题组，诗句居中，保留句读、换行、分节。
- **嵌入叙事的诗**：诗块整体居中，句子较长或不等长时允许块内左对齐、续行缩进。
  优先保持一联的连续阅读；有原版证据才恢复两联间的分节，避免每句都隔一个大空段。
- **献词／题辞**：短行组成一个整体居中的块，块内可左对齐；比较逐行居中候选。
  日期、署名可以右对齐，不能把前一篇末日期一同移进献词。
- **散文引文、花谱小传、书信、布告**：通常略收左右边距、块内左对齐，字号接近正文。
  书信落款／日期可右对齐；引文内部的诗单独处理。普通人物对话仍属正文。

避免通过连续空格、全角空格、固定像素宽度或代码块排诗；不要给所有 quote 套居中、
斜体、边框或大幅缩小字号。短诗可以尝试避免跨页，长引文须允许分页，防止制造空白页。
字体放大后保持文字可见，不能用固定高度和裁切隐藏溢出。

### 标点与空格

先看真实字符，再看 CSS 和阅读器两端对齐。截图中的大空隙可能来自 `text-align: justify`、
字距、全角标点或不换行空格，不能只靠删空格解决。

- 复用共享规范化报告，逐项检查引号方向、中文标点周围空格、段首伪缩进和中西文边界。
- 英文句子／参考文献按局部语言片段审核：确认后可将其中的全角括号、冒号、逗号、
  分号改为英文形式，并整理词间空格。中文叙述和中文引文继续使用中文标点。
- 英文书目块首选左对齐、自然换行；仅在条目边界清楚时考虑悬挂缩进。保留姓名、
  题名、卷期、年份、页码、大小写、撇号、重音和有意义的连接符；不凭外观重写引用格式。
- 紧随译文的括号内原文与译文构成一组，通常保持在同一段连续排版；不能仅因语言变化
  或英文较长就拆成独立引文块。只按局部语境整理括号和空格，保留原有对应关系。
- URL、邮箱、DOI、代码、公式、脚注身份及双语原文保护规则继续生效。字体差异不能作为
  改字依据。疑似错字、异体字和版本差异记录为待校勘；没有证据时保留原文。
- 古文、异体字、生僻字和 CJK 扩展区汉字均是有效内容，不能因字频低、词典不收录或
  文体古奥就标为错误。审核规范化差异时核对这些字符及异体字选择符的完整保留；字体
  缺字、源文已有缺字框／替换字符与内容错误分别记录，不自动改成常用字或现代写法。

英文全角标点的局部修复若现有共享脚本未覆盖，记录精确前后片段与位置，经审核做
本书定点修复；不得声称通用 normalizer 已经具备此能力。

### 封面

先查看原图和 120–160 px 高的书库缩略图，审核书名／作者清晰度、有效画面和白边。
EPUB 没有适用于所有书库的强制统一封面像素尺寸。这里把 **宽:高 = 5:8**、新制或
确需重做时 **1600 × 2560 px** 作为书库候选规格，不宣称它是 Apple Books 的硬性标准。
已是 5:8 且缩略图清楚的封面可保留原像素，不为凑大尺寸无意义插值。

不同比例优先等比放入统一画布，背景延展／补边后预览；裁切要确认不损失书名、署名、
出版社及重要画面，禁止直接拉伸。若书库把画面内白边也算入封面，需同时检查有效画面高度。

模糊扫描先寻找**相同版次**的清晰封面；仍不清楚时，用图像编辑工具以原封面为参考
做修复候选，保留构图与版次信息。书名、作者须对照原版逐字检查，尤其中文；生成图
不能作为文字事实来源。必要时用准确字体重新排字，但标明这是重制候选而非原版扫描。
先展示原图／修复图／缩略图对照，再随该版本的确认一并采用。

检查 OPF 封面声明和图片 MIME／尺寸。最终封面是书库缩略图资产，不新增独立阅读页；
来源已有封面页时，把从 spine／封面导航移除的具体变更列进预览清单，保留封面图片。

### 文件名与元数据

所有 EPUB 的文件名只保留书名和扩展名，例如 `品花宝鉴.epub`、`台北人.epub`。
文件名不含作者、下载站、宣传语、丛书或“简体中文版”等版别后缀，也不加书名号。
文件保持在原目录；仅当用户原本选择仓库书库时，才使用 `books/<作者>/<书名>.epub`。
版别和作者等有效信息保留在经审核的元数据或版权页。先给出原名→拟定名称，再应用；
目标重名时检查内容与版次，以目录区分或请用户选择，不能擅自覆盖或往文件名追加后缀。

逐字段展示 `title/creator/language/publisher/date/identifier/description/series` 的现值、
建议值、依据和是否变更。清除经确认的下载站后缀、推广语和工具广告；有网址不等于垃圾：
版权页出版机构信息、正文参考链接和合法来源记录按其用途保留。

保留真实副标题、译者、版次和丛书信息；把“简体中文版”等从标题移出也要列为决定。
缺失日期保持未知，区分版权年、修订日、出版日与修改时间。保留稳定书籍标识；EAN、
ASIN、UUID 不能猜成 ISBN。简介与实际章节计数冲突时先核对是否含序言，不凭简介增删章节。

### 广告与版权页

逐本检查书前、书后、目录及章内插入的推广内容，包括下载站广告、引流网址／二维码、
加群文字、付费资源推广和重复站点署名。结合上下文与来源判断，不把网址或“版权”关键词
当成删除依据。作者后记、真实出版信息、致谢、参考链接及版权声明保留。
预览列出拟删除的页／片段和理由；独立广告页删除时同步检查 manifest、spine、NAV、NCX、
可见目录及图片引用，清理只被该广告使用的资源，保护仍被正文引用的内容和目标锚点。
隐藏 metadata 中的下载站推广也按相同原则审核。

版权页按书名、作者／译者、版次／丛书、出版信息、标识与声明分组，优先紧凑左对齐。
书名加粗，其他字段用一致字号和适量段距；标签保持完整，长网址／地址自然折行。
不使用全角空格撑出字段对齐，也不把长篇声明两端强行拉伸。法律声明与版权归属逐字保留；
真实出版社联系方式不当广告删除。无证据不补日期、ISBN 或版次，用户明确指定的元数据
与原版权页的历史记载分别记录，不能自动改写版权页来使两者看似一致。
版权页也是独立预览类型：展示实际原页与候选，确认后应用，并核验文字完整及窄屏显示。

### 扉页标签与照片

扉页装饰性的系列角标、排版制作者标签可按用户要求移除；它们不自动等于广告。
真实丛书信息仍可保留在 metadata／版权页，不能连同正文照片或图注误删。
照片与图注组成居中的整体，按纵横比例设置适合屏宽的显示宽度、最大宽高和适量间距；
合影适当更宽，竖幅肖像保留上下空间。不要直接拉伸、裁掉人物或分离图注。
检查原始像素：小图可适当扩大显示，但须说明清晰度限制；不把生成式补细节当成真实
历史影像。单幅、合影／多图页都应预览，并核验窄屏、大字与跨页时图注的对应关系。
放大后明显模糊时，先查同版或可靠版本的对应照片；逐张核对人物、构图、裁切和图注，
记录来源与文件哈希，只替换确认对应的图。显示尺寸也要依据像素质量设上限，不能只按
页面百分比放大；没有清晰来源时保守显示，不把插值或生成细节当成修复成功。
同批处理的书须逐本检查卷首照片，不能只修用户截图中的那一本。不同平台的现行版本
可能不收插图；可继续查可靠出版或档案来源，但不以相似人物照代替同一照片。来源图注
与原书日期不一致时单列待校勘，排版或换图本身不授权改写原书图注。

## 3. 制作预览并等待确认

先做成可审阅结果，再请求用户确认。每种拟改动的版式至少一例，并覆盖最容易溢出或
误判的例外；常见组合是章首、复杂标题组、数字小节、诗、长引文、英文书目、封面和
文件名／元数据表、版权页与广告清理清单。本书没有的类型标记“不适用”，不用无关样例冒充本书实测。

预览包含原文与候选并排、具体改动说明和定位信息；有真实选择时给两种方案，并说明
首选理由。用原 EPUB 的实际文字；前后对比保持相同视口、字体、字号和主题。注明原版
是否因阅读器主题模拟了链接色、边距等。允许窄屏、宽屏、大字、浅色／深色检查。
完成并检查预览后自动在本机浏览器打开，同时给出可再次打开的链接。

HTML/CSS 预览能确认字重、对齐与相对间距；不能证明 Apple Books／Readium 的分页。
需要阅读器验证时，可在临时目录制作显著标为“预览”的独立候选 EPUB，不能覆盖原书或
导入生产书库。浏览器效果通过后，最终候选仍需阅读器检查。

审核记录至少保存：输入哈希、预览版本、位置／原片段校验、问题类别、候选改法、理由、
适用范围、用户选择和未决项。这是人工审核记录，不是已有 CLI 接受的配置格式。
“确认这版”只覆盖已展示的版本和范围；之后发现新文体或更改方案，先补充预览。

**停点：用户确认前，不覆盖或重命名原 EPUB，不写最终库内文件，不更换正式封面，
不发布到 Notion／NAS／Apple Books。** 可以继续只读审核和完善预览。
确认后直接完成已授权范围，不重复征求同一项许可。

## 4. 应用、回读与完成

确认记录绑定原文件哈希。执行前重新检查源文件与目标冲突；源变化时重做差异审阅。
优先使用已有维护能力；逐本定点修改用 XML 解析和精确匹配，匹配数量不符就停下复核。
保留图片、字体、脚注、链接、锚点和阅读顺序。只为样式修复时，优先保留 archive member
与 ID，避免无必要的整书抽取重建；需要重建则检查共享输入是否能完整表示该书结构。

按[档案完整性约定](local-editions.md#archive-integrity-and-verification)写临时 EPUB，
验证后原子安装到原文件所在目录（或用户明确指定的位置），替换原文件；需要重命名时，
在回读验证成品和临时备份后移除旧名称，避免把两个版本同时留在用户书库。备份按存储
约定放在书库之外，不把仓库 `books/` 当作默认输出位置。只应用已确认变化；全量 normalization 可能包含未批准的
编号／结构变化，不能在结尾无条件运行。既有正常化报告的零问题也不等于视觉精校完成。

验收须覆盖：

1. ZIP CRC、XML、`mimetype` 首项且不压缩、manifest／spine、NAV／NCX 全部链接与锚点。
2. 全部章节顺序、标题、目录一致；逐成员对比，正文改动只能来自批准的标点／结构差异。
   拆段前后逐字比对，排除诗句、引文、重复段落和脚注丢失。
3. 全书所有受改角色的字重、主题色、间距一致；窄／宽屏、大字、夜间模式无裁切。
   阅读器检查章首、诗块分页、长引文及脚注。未实测的平台明确标为未验证。
4. 封面图可解码、封面声明正确、库内缩略图可读，最终文件名与 OPF 的书名／作者一致。
5. 重复执行同一组已批准变换不产生新差异；重新读取最终 EPUB 并记录哈希。

最终报告区分“已应用”“保留／待校勘”“只做了预览”，附最终文件或预览路径。
